Lexical Analyzer

Project Overview

A lexical analyzer implemented in C that demonstrates the initial phase of a compiler.

Objective

To understand how source code can be processed into tokens using C programming concepts.

Concepts Used

- C Programming
- Strings and Character Handling
- Conditional Statements and Loops
- Functions (if implemented in the project)

Project Features

- Processes input text (as supported by the implementation)
- Identifies tokens (as supported by the implementation)
- Demonstrates basic lexical analysis concepts

Technologies Used

- Programming Language: C
- Compiler: GCC (if used)

How to Run

Compile the source files using the appropriate GCC command for this project.
